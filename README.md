# Library Website Design in Figma

A UI/UX design project created in Figma for my **Internet Studies and Web Design** coursework. This repository showcases digital experiences designed for modern library services, bridging user-centered visual design with foundational web implementation.

---

## 🏛️ Project 1: Public Library Website Design

The core objective of this design was to create an inviting, accessible digital presence for a public library. 

### Key Design Highlights
* **Visual Identity & Color Palette:** Utilized warm, welcoming tones to evoke a comfortable reading environment, moving away from sterile, traditional portal aesthetics.
* **Architectural & Heritage Elements:** Blended subtle architectural motifs and cultural heritage accents into the layout, reflecting the library's physical identity as a community landmark.
* **User-Centric Navigation:** Built intuitive menus, quick-access catalog search points, and clear service sections tailored for readers of diverse digital literacy levels.

## 💻 From Design to Code (HTML Implementation)

As part of the coursework and learning process, the Public Library Figma mockup was translated into clean, semantic **HTML**. 

* **Beginner-Friendly Codebase:** Built to demonstrate the fundamental transition from static wireframes and prototypes into living web elements.
* **Structural Clarity:** Focuses on clean DOM hierarchy, readable tags, and accessible content organization for future CSS styling and responsive integration.

# Library-Website-Design-in-Figma 
A library website design created in Figma for my Internet Studies and Web Design coursework. I focused on building a clean, user-friendly layout with intuitive navigation.

As part of my learning process, I also translated the Figma design into basic HTML. The code is structured to be simple and beginner-friendly, demonstrating how a UI/UX concept can be brought to life on the web.
